Privacy Policy

Investment Agent · last updated 4 September 2026

Who this covers

Investment Agent is a private automation operated by a single individual for their own use. It has one user: its author. It is not offered to, marketed to, or usable by anybody else, and it does not collect information from third parties.

What data it accesses

When authorised, the application accesses Google account data belonging solely to the person who authorised it:

  • Google Sheets — reads and writes a single spreadsheet owned by that user, which holds configuration, research records and simulated trading history.
  • Google Drive — locates that spreadsheet and, where enabled, creates backup copies of it in the same user's Drive.
  • Gmail — where enabled, sends notification email from the user's own account to that same account.

It does not read unrelated files, unrelated mailboxes, contacts, calendars, photos or location data.

How that data is used

Solely to operate the automation on the user's own behalf: reading configuration, recording research output and simulated positions, and sending the user notifications about the state of their own workflows.

Sharing and disclosure

No data is sold, rented, shared, transferred or disclosed to any third party. There is no advertising, no analytics, no profiling and no tracking. Data is not used to train machine learning models.

Storage and retention

Data remains in the user's own Google account. Operational records are written to the user's own Google Sheets workbook and to a self-hosted n8n instance under the user's control. OAuth tokens are stored encrypted by n8n on that instance and are used only to make API calls on the user's behalf.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately invalidates the stored tokens. The user may also delete the credential from the n8n instance.

Security

The n8n instance is served over HTTPS and access to it is restricted to the operator. Credentials are stored encrypted at rest by n8n.

Changes

Any change to this policy will be published on this page with an updated date.
